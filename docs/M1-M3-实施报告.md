## M1 身份聚簇

- **方法**：代表点（seed）法 + 收尾 seed 并查集合并——防相似度传递串簇，消除建立顺序偏差；全程不构造 N² 矩阵。
- **坏脸门控**（落 R9 尾部）：det_score < 0.50、脸框面积 <2%、短边 <48px、关键点塌缩/越框、嵌入缺失。
- **结果**：450 张 → **277 簇**（208 个单图簇），尾部 坏脸 3 / 无人脸 0 / 失败 0；簇大小 top10 与单图簇数符合混合头像包预期。
- **簇属性**：成员众数，并列取 medoid 图属性（R6）。

## M2 硬分区 + 排序 + 重命名

- **硬分区**（R4）：键序层级分段，簇号全局 1..N 连续、不补零（R12）；无脸尾段占末簇号。
- **排序**（R5/R7）：段内贪心最近邻链（首段起点=检测分最高，段间衔接末簇），簇内到 medoid 余弦降序 + face_pHash 汉明并列裁决。
- **F 值**（R11）：默认键序 肤色→发长→发色 基线 **F(L1)=139.9 / F(L2)=137.2 / F(L3)=129.58**（113 叶段）；2026-10-20 发色量纲 bug 修复后重算为 **F(L1)=141.6 / F(L2)=139.0 / F(L3)=132.8**（108 叶段，簇数仍 277+尾部）。
- **重命名**（R8）：copy 模式 450 张副本逐文件 content_hash 全等；inplace 两阶段改名在沙箱演练中触发中途失败 → 自动逆向回滚逐字节恢复；冲突（目标被占且内容不同）正确拒绝。
- **发型键叠加**：hairstyle.json 图级标签 → 簇级众数（并列取组序靠前），274/277 簇有效；`肤色→发长→发型` 键序 F(L4)=118.5。

## M3 发型三模式 + GUI

- **嵌入**：SigLIP2 ViT-B/16 FP32，发区掩码置灰构造输入，token 均值池化 768 维；450 张 12.8s（DML ~35 张/s，§3 预算内）；发区占比 <0.5% 判掩码不可靠标记无效（447 有效）。
- **三模式**：
  - B 聚类（默认）：K 自动轮廓系数 [2,12] → **K=12**，组分布 top [88, 60, 57, 54, …]；
  - A 固定清单：20 类零样本 → 9 类命中（229/183 双主类），提示词嵌入预计算缓存后不再加载文本塔；
  - C 示例标注：3 示例 → 3 组 [357, 52, 38]，示例间 cos>0.9 告警正常触发。
  - 三模式共用 hair_emb 缓存，切换零重算。
- **GUI**（PySide6）：按管线顺序的**六步导航**（左侧步骤条显示"我在第几步/哪步已完成"）——
  ① 准备（目录与环境就绪状态、就地下载、GPU 自检、一键全流程）；
  ② 标注（图片上限/识别包/掩码/GPU，结果概览 + 发色·肤色·发长分布条形图）；
  ③ 聚簇（同人阈值可调，medoid 代表图网格，多选合并 / 单选拆分并在完成后自动重排）；
  ④ 发型（三模式切换、组卡片合并/拆组、模式 A 清单编辑、软排序开关、盘束疑似交叉核对、一键应用为分区键）；
  ⑤ 分区排序（键序拖拽+勾选，300ms 防抖自动重排，F 值面板，可搜索原名/新名/段的预览表）；
  ⑥ 输出（前后名对照、冲突与漂移红标、copy/inplace 可选、预演/执行/回滚、生成并打开排序报告与接触表）。
  底部日志坞可折叠，后台任务单任务互斥并回传进度。
- **软排序**（§4.3"或软排序权重"）：不改硬分区段路径，段内按发型组分桶分层链；450 样本上段内 63 簇顺序变化。
- **回退档**（§4.1）：掩码缺失/off 时肤色（脸颊+额头补丁）与发色（头顶几何窗口）降级可用，发长不猜测。
