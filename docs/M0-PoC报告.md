## 4. 调试中发现并修复的 bug（按发现顺序）

1. **掩码归一化探测用错坐标系**：脸框（原图坐标）没缩放到 256 空间就裁剪 → 探测选错归一化 → 类图全噪声。修复 + 加"logits 荒谬值（>1e4）防御"。
2. **OpenCV 浮点色空间输入未归一化**：BGR2Lab/BGR2HSV 的 float 输入要求 0-1，原实现用 0-255 导致 L*/a*/b*/S 全部失真（肤色误判根源之一）。
3. **发色未限定头区 ROI**：Overmars 深蓝外套被掩码误吸进发区 → 误判蓝发。修复：脸框上 0.9H~下 0.4H ROI。
4. **暗发色相噪声**：近黑像素 HSV 色相无意义 → 深棕发误判蓝发（蓝 57→11 的根因）。修复：V<0.12 或 L*<22 直接判黑；色相路径加置信度下限 0.45（低于则弃权）。
5. **发长低估**：披肩发在"脸框±0.5W 竖带"外 → 补全宽 bbox 底边取 max。
6. **发色判定正确的案例**：秃头（含络腮胡）正确判光头+发色弃权；幻想蓝发保留 11 张真蓝发。

## 9. 校准日志 · 轮①（2026-10-06，用户真值反馈）

**需求变更**：肤色改为 **0-19 级**（越大越深，描述词 白皮肤/黄皮肤/黑皮肤 映射区间）；默认键顺序改为 **肤色 → 发长 → 发色**。

**用户错例（12 张）**：黑发应棕 ×5、中等肤应黑皮肤 ×5、短发应长发 ×2。

**诊断与修复（4 项）**：

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 深棕发判"黑" | 暗发分支直接跳过色相 | 暗发（L*<30）加"暖色相一致率"检验：conf≥0.40 且色相 ∈[12°,58°] → 棕 |
| 2 | 亮光深肤判"黄皮肤" | ①uint8 Lab 缩放约定错误（a/b 偏移 128 未减、L 按百读）②灰世界白平衡把皮肤色度中和成灰 → ITA 退化成"只看亮度的单调函数" | 弃用白平衡与 ITA，浮点 Lab 直读 L*+C*，重建 0-19 级评分 eff=(100−L*)+min(C*,22)×1.0 |
| 3 | 卷发/爆炸头判"短发" | d（越下巴延伸）对"向上/向两侧长"的发型全盲（两例 d=0.00） | 新增体积双条件：vol=发量/头区 ≥1.30 且 wide=发区最大行宽/脸宽 ≥1.30 → 长发 |
| 4 | 肤色 ITA 分布挤压 | 同 #2 | 0-19 级替代三桶 |

**复核结果（12 例）**：黑发→棕 **4/5**（3352 conf 0.37 差线 0.03，残余）；黑皮肤 **4/5**（African95 差 1 级，残余）；长发 **2/2**。对照组无回归：真深肤 Zogbé=19 / African66=16 顶格，浅肤对照 6，光头正确弃权。

**最终分布**：肤色级白 0-5 共 219 张、黄 6-10 共 150、黑 11-19 共 81；发长 短发297 / 长发99 / 寸头28 / 超长16 / 光头4 / 中长发6；发色 黑215 棕143 灰45 无效15 白11 金黄11 绿9 红棕1。

**已知残余（物理边界）**：
- 2748 型"阴影浅肤"落在 12（黑皮肤区）——面部色块与亮光深肤同值（L*46 vs 41 的两例），人眼的场景色彩恒常性无法用色块复现 → M3 零样本交叉验证；
- 3352 深棕发 conf 0.37（差 0.03）；
- 红棕桶被暗发分支吸收（20→1），暗红色相归入棕——如需区分深红发再加桶。

**接触表**：分组已改为 肤色级 → 发长 → 发色（新默认键序）。

**修复（4 项）**：

**复核结果（27 例标注维度）**：**19 ✓ / 8 ✗**。分项：发色 4/5、发长 6/7、肤色 9/15...（精确：肤色 10/16）。

**残余 8 例（全部定性）**：

| 案例 | 现状 | 定性 |
|------|------|------|
| African93/95/97、Mbaye（应黑皮肤，现 7-11 级） | 面部 Lab 比黄皮肤对照组**更亮**（African93 L*=49 vs 3068 L*=38） | **物理不可分**：人眼用了发质/五官/场景色彩恒常性，纯色块无解 |

### 10.1 轮②追加：四组规则实验（应"继续调规则"要求，全部阴性）

| 实验 | 设计 | 结果 | 结论 |
|------|------|------|------|
| 发质纹理（孔洞密度+边缘粗糙度） | 卷发/爆炸头掩码应更破碎 | 孔洞全为 0（256 掩码无内部纹理）；粗糙度方向相反（黄肤组 12-13 > 黑肤组 5-8） | 掩码分辨率不足以表达发质，弃 |
| 场景偏色校正（中性亮区估计色偏） | 修 African93 的蓝球衣反光 | 修正量微小（±1-6）；修复 Asian26/3068 的同时打坏 2748/1433，净 -1 | 弃 |
| 掩码膨胀补偿（浅发低对比少记） | 膨胀 2 轮后重测上区比 | 67253769 0.143 vs 219 0.156——仍反向 | 弃 |
| 发像素空间集中度（光头残茬均匀 vs 短发成峰） | 4×4 格最大密度 | 219 峰 0.551 > 67253769 峰 0.434，仍反向 | 弃 |

**结论**：219（光头）与 67253769（短发）在掩码一切几何特征上反向——前者的深色胡茬对比强、后者的浅金发在浅肤上对比弱，256 分辨率掩码无法区分"剃光的残茬"和"浅色短发"。规则路径的证据链已闭合：**8 例残余维持现状，后续出路是语义级模型（SigLIP2 零样本交叉验证，随时可引入）**。M0 机制部分到此收口。
